# Lucas Fiala – Portfolio

Static site (HTML, CSS, JS). Deploy with GitHub Pages (branch `main`, folder `/ (root)`).

```
index.html            Home
about.html            About
cases/unicef-seal.html
assets/css/style.css  Shared styles
assets/js/main.js     Slider + scroll animations
assets/img/           Put your images here
```

## Edit
- Images: replace each `<div class="ph">…</div>` with `<img src="../assets/img/file.webp" alt="…">` (use `assets/img/…` without `../` on index/about).
- New case: copy `cases/unicef-seal.html`, edit the content, then link it from `index.html` (replace a `.work.soon` block with an `<a class="work" href="cases/your-case.html">`).
- LinkedIn/Behance: update the links in `index.html`.
